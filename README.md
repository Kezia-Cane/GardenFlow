# GardenFlow Analytics

A polished MVP analytics dashboard prototype for an AI-powered YouTube and e-commerce company. It combines creator performance, web store metrics, and cross-channel revenue into one dark premium SaaS dashboard.

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- Recharts
- lucide-react

## Features

- Combined Overview with unified revenue, funnel, insights, and recent activity
- YouTube Channel Metrics with KPIs, charts, table, and channel filter
- Web Store Metrics with KPIs, charts, table, and store filter
- Responsive dark dashboard layout inspired by the local Stitch reference
- Mock data with reusable calculation helpers
- Deployment-ready static frontend with no backend, auth, database, or API dependency

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import the project in Vercel.
3. Use the default Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`
4. Deploy.

## Trial Scope

This was built as a 48-hour prototype for a Vibe Coder / Prompt Engineer trial. The goal is to show fast product judgment, clear implementation, and a working dashboard that feels useful without being overbuilt.
